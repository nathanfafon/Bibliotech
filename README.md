## Objetivo do Software
O BiblioTech serve para automatizar o gerenciamento de bibliotecas, permitindo o controle centralizado de acervos, usuários e a movimentação de empréstimos, garantindo a integridade dos dados e agilidade no atendimento.

## Funcionalidades (Requisitos)
- **RF01:** Cadastro e gerenciamento de livros (Título, Autor, Editora).  
- **RF02:** Cadastro e gerenciamento de usuários (Nome, CPF, Contato).  
- **RF03:** Registro e controle de empréstimos e devoluções.
